29. Persistent Attention：任务循环与尾波

本章可运行语义基线：persistent 静态任务顺序的 gather；真正循环 CTA attention 见原书 CUDA demo。

Triton 用 program ID 加固定 grid stride；TileLang 用同样任务循环。先用整数 task ID 写 marker，检查每个 marker 恰好一次，再接 attention。测试 tasks=1/P-1/P/P+1，包含 causal 不均匀负载。

进阶验收：任务无漏算/重算，短长序列都测；比较整段时间，不能预设胜过厂商库

独立学生入口：student_triton.py / student_tilelang.py 的 solve(problem,backend)。
输入由 exercises.make_problem(chapter,variant) 生成；参考由 expected 独立计算。
4 个 case 包含小形状、零输入、非整除维度与 causal/布局变化。
初始学生入口明确抛 NotImplementedError，不会冒充已完成练习。
基线通过不代表进阶硬件机制已经实现。
